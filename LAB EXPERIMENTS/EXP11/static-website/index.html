Hello from Docker!

This static website is served by an Nginx container.

About

CSA10 Software Engineering - Lab Experiment 11. A simple HTML page packaged into a Docker image and served with Nginx.

How it works

Dockerfile copies index.html into /usr/share/nginx/html, and Nginx serves it on port 80.

Run it

docker run -d -p 8080:80 static-website then open http://localhost:8080
