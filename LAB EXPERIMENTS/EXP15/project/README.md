# Team Project - Student Portal

## Modules
- **auth** - login and roles
- **payments** - fee payment
- **ui** - home page

## Workflow
1. Create a branch per module: `git checkout -b module/<name>`
2. Commit small changes and push the branch.
3. Open a Pull Request; at least one teammate reviews it.
4. Fix review comments with new commits on the same branch.
5. Merge with a merge commit (`--no-ff`) into `main`.
6. If there is a conflict, merge `main` into your branch, edit the file, `git add`, commit.
