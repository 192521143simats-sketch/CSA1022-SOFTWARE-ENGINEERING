# Step 1: create the repository on GitHub with a README (here: a bare repo seeded with README.md)

$ git init --bare -b main remote/my-personal-project.git
Initialized empty Git repository in /home/claude/lab/exp20/remote/my-personal-project.git/

$ git clone remote/my-personal-project.git seed
Cloning into 'seed'...
warning: You appear to have cloned an empty repository.
done.

$ git add README.md && git commit -m 'Initial commit'

$ git push -u origin main
